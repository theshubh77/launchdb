# LaunchDB - 100+ Active Directories & Launchpads to Launch Your SaaS

[![Vercel Deployment](https://img.shields.io/badge/Deploy-Vercel-000000?style=flat&logo=vercel&logoColor=white)](https://launchdb.vercel.app/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg?style=flat)](LICENSE)

LaunchDB is an open-source directory platform designed for developers, founders, and indie hackers to submit their SaaS to 100+ web directories, subreddits, X communities, Facebook groups, and GitHub repositories to find early adopters and build high-quality SEO backlinks.

### 💡 Why LaunchDB?

A few months ago, we created the **[awesome-saas-directories](https://github.com/theshubh77/awesome-saas-directories)** repository with the same goal as LaunchDB: helping founders find launch directories. While the project received great feedback and community support, we noticed that browsing a raw markdown list and opening GitHub Pull Requests to suggest new directories was challenging for non-technical users. LaunchDB was born to make this process simple and accessible, offering a clean, beautiful web interface for everyone.

Live Website: **[https://launchdb.vercel.app/](https://launchdb.vercel.app/)**  
GitHub Codebase: **[https://github.com/theshubh77/launchdb](https://github.com/theshubh77/launchdb)**

## 📂 Data Source

The directories listed on LaunchDB are powered by the **[awesome-saas-directories](https://github.com/theshubh77/awesome-saas-directories)** repository. This is a community-curated collection of platforms, subreddits, and directories designed to help developers and founders find launch opportunities.

## 🤝 How to Contribute

We welcome and appreciate all contributions!

*   **To suggest or submit new directories**: Please refer and contribute to the **[awesome-saas-directories](https://github.com/theshubh77/awesome-saas-directories)** repository, which hosts the master list of directories.
*   **To improve the LaunchDB website codebase**: Please feel free to open a Pull Request (PR) directly on this repository!
